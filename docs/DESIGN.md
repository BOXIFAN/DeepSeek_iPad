# 设计规范 · 浮岛骨架

2026-11-24 定稿。四个方向里选了「浮岛」，这份文件记的是它的取值，新页面照这里做，不另起一套。

## 一句话

对话就是首页。屏幕上只有一张纸、一条居中的正文列和一个浮起来的输入框；会话历史与余额都在需要时才出现。

## 骨架

| 位置 | iPad | iPhone |
|---|---|---|
| 顶栏 | 左历史、中标题、右新对话，高 38 的圆形按钮；材质底 + 0.5pt 分隔线，内容不穿过 | 同左，边距收紧到 18 |
| 正文 | 宽 660 居中，左右各留 186 | 宽受屏幕限制，边距 24 |
| 输入区 | 底部常驻，宽 640 居中 | 宽满，边距 16 |
| 历史 | 左侧 320 宽抽屉 + 26% 黑遮罩 | 半屏 sheet（medium / large） |
| 余额 | 左下角 150 宽卡片 | 输入条模式行右侧的胶囊 |

内容区顶部留 104，给悬浮顶栏让位；正文列左右不画边框、不加背景，靠留白分组。

## 颜色

| 角色 | 取值 | 用在哪 |
|---|---|---|
| 品牌蓝 | `#4D6BFE`（`Theme.accent`） | 发送键、选中态、链接、新对话按钮 |
| 页面底 | 浅色 `#F8F9FF → #FFFFFF` 竖向渐变；深色 `#0E0F14 → #060608` | 全屏背景 |
| 气泡 | `secondarySystemBackground` | 用户消息、建议卡 |
| 表面 | `systemBackground` | 输入框、顶栏按钮（深色改用 `secondarySystemBackground`） |
| 描边 | `Color.primary.opacity(0.08)` | 输入框、卡片、按钮 |
| 警示 | `.orange` | 余额低于 ¥20、Key 失效、余额超限 |

深色模式全部走系统语义色，不写死 RGB（背景渐变除外，那层需要压得更暗）。品牌蓝在深色下保持原值。

## 组件

- **顶栏按钮**：白底圆 + 12 半径阴影 + 1px 描边。三个按钮不同时强调，只有「新对话」用品牌蓝。
- **模式胶囊**：`思考 · 档位`（点开选四档）/ `联网搜索` / `技能 · N`（点开勾选），开启时品牌蓝文字 + 10% 蓝底，关闭时灰色文字 + 4.5% 主色底
  - 四个胶囊挤一行时用 11.5 号字、8 内边距、`lineLimit(1)` + `fixedSize`，不允许折行
- **顶栏**：材质底延伸到状态栏，底部一条 0.5pt 分隔线；正文永远在分隔线以下，不做「文字从标题下穿过」的渐变。
- **输入框**：白底圆角 26，无边框感靠阴影和 1px 描边；左内边距 18，右侧发送键 32 圆。流式时发送键变停止键。
- **余额卡片**：三行（标签 + 刷新图标 / 金额 / 状态）。低于 ¥20 时金额橙色；刷新失败保留已有金额，只在状态行写「HH:mm 更新 · 稍后自动重试」，不把数字染橙。轻点刷新（出错也是重试），长按看明细。
- **文件附件**：输入条左侧回形针进入文件选择。待发文件是 224 宽的卡（类型图标 + 文件名 + 状态），横向滚动；上传中显示转圈与「上传解析中…」，就绪显示大小，失败转橙框、副行「上传失败 · 点一下重试」，失败详情在文件条下方一行。卡片右上角 × 删除。有 PDF / Word 时下方出现「保留文档里的图」开关（默认关），切换会重传已解析文件。已发送的文件卡在用户气泡上方，图标用品牌蓝、副行「大小 · 解析方式」。
- **会话指标条**：输入框下方一行，10.5 号字、数字等宽、`secondary`。三段用 1pt 竖线分隔：`◯ 上下文剩 972K │ 缓存命中 88% │ 46 tok/s`。环 11 × 11、线宽 1.8，填的是**剩余**比例，与文字同义；剩余不到 15% 时环与数字转橙。没有缓存/速度数据时对应段整段不出现，不留空位。点睛：点开「会话用量」弹层（430 高），里面给已用 / 剩余 / 本轮输入输出 / 思考 token / 窗口大小。
- **建议卡**：一行问题文字 + 右上角箭头，点了只填进输入框，不直接发送。
- **图片**：输入条左侧 `photo` 图标进入选图，待发图在预览条里 62×62 圆角 12，右上角 × 删除；发送后进用户气泡——单张按原比例（宽 232、高 120–300），多张排两列方图（2 张 148、3–4 张 104）
- **全屏看图**：纯黑底，图片铺满；左上关闭、右上 `1 / 3` 用 18% 白胶囊；底部 54×54 缩略图条（选中加 2pt 白描边），只在多于一张时出现
  - 向下拖 140pt 关闭，背景随位移变淡（最低到 35%）
  - 长按出「保存到相册」「复制图片」，操作后顶部一行短暂确认
- **压缩进度**：输入条上方一行，小号转圈 + 「正在处理 1/3 张」，不与待发预览条同时出现

## 动效

只保留三处，全部 ≤ 0.2 秒：

- 历史浮层：抽屉位移 360pt + 遮罩 0 → 0.26 同步，`.spring(response: 0.30, dampingFraction: 0.86)`；关闭用同一条曲线
  - 用 spring 的理由是开头有加速段：16ms 时 easeOut 已走 9.4%，spring 只走 4.6%；100ms 时 spring 反而更快（67.7% vs 51.8%）
  - 峰值 1.005，过冲 0.5%，肉眼不可见
- 模式胶囊开关 `.easeInOut(0.15)`
- 流式跟随滚动不加动画，避免高频抖动

## 设置与提示词

设置沿用系统表单（`Form` + `NavigationStack`），不套浮岛那套留白——这里要的是可预期的分组和行高。

- 首页分区顺序：API Key → 模型 → 默认开关 → 提示词 → 删除 Key
- 「提示词」分区两行，右侧给摘要（`58 字` / `已启用 2 个`），footer 报出拼好后的总字数
- 系统提示词页：`TextEditor` 最小 260 高，下面单独给字数与清空；提示词不进对话记录，只进请求
- 技能页：行内是名称 + 内置徽章（灰色）+ 启用徽章（品牌蓝）+ 一句话说明 + 字数；左滑启停、右滑删除、点进编辑
- 技能编辑页：名称、说明、指令、启用、删除，顺序固定

## 不要做的事

- 不给正文列加卡片外框、侧边栏常驻、导航栏
- 不做纯装饰的渐变、光晕、玻璃叠层
- 不放没有实现的按钮（图片上传、语音目前都不在界面上）
- 不在画面上写「示例」「未接入」这类制作说明

## 图标

App 叫**鲸语**，图标是米白底 `#F4EEE4` 上的深墨剪影蓝鲸（原创，不是官方 logo）：单色剪影、负空间眼睛与鳍线、背上方三滴水花。资源是单尺寸 1024 的 `AppIcon-1024.png`，放在 `Sources/Assets.xcassets/AppIcon.appiconset`，工程里 `ASSETCATALOG_COMPILER_APPICON_NAME = AppIcon`。鲸鱼主体占画布约七成，四周留白要够；不要给图标加文字、渐变或描边。
